# EMBERFALL · 잿불의 성역

한국어 1~2인 로컬 협동 액션 RPG. 블록 형태의 캐릭터, 연속된 평원 균열, 장비와 룬으로 바뀌는 직업 빌드.

- 공유 개발 저장소: https://github.com/ripper025-max/-
- 공개 게임: https://emberfall-dungeons.limsingeol.chatgpt.site
- 다른 PC / Codex에서 이어서 작업: [HANDOFF.md](HANDOFF.md), [AGENTS.md](AGENTS.md)

Node.js 22+에서 `npm start` 후 http://127.0.0.1:4173 을 연다. 설치나 빌드가 필요 없다. `dist/`가 편집 가능한 원본이다. Windows는 `START_GAME.cmd`로 실행할 수도 있다.

## 현재 게임

- 전사·원소술사·사냥꾼·도적·강령술사·용병·드루이드·수도사 8직업.
- 직업마다 전용 무기 1종. 다른 무기로 바꾸는 구조는 폐지했으며 같은 종류의 등급·옵션·전설로 성장한다. 기존 저장 무기는 능력치·옵션·ID를 유지한 채 해당 직업 무기로 전환한다.
- 직업별 스킬 5개 중 3개 장착. 총 40스킬, 80룬 선택지. 마을에서 교체하며 강화 단계는 슬롯에 유지된다. 교체 시 룬은 기본형으로, 기존 소환과 지대는 해제된다. 재사용 시간은 초기화하지 않는다.
- 전설 효과 24개. 직업별 시너지가 룬과 함께 작동하며 강령술사는 소환 증가·영구 유지·궁수/골렘 혼합을 조합한다.
- 일반 몬스터는 플레이어마다 독립적으로 30% 장비 추첨. 정예는 각자 희귀 이상 장비 1개. 보스는 각자 직업에 맞는 보상 목록에서 전설 1개. 막타·피해 기여와 무관하며 누구든 주우면 지정된 주인에게 전달한다. 동일 직업 2인도 별도 추첨한다.
- 가방 72칸. 초과 장비는 프로필의 보관 대기함에 영구 저장되며 자동 판매되지 않는다. 가방에서 빈칸만큼 받는다. 경험치·골드·강화 파편은 협동 공유.
- 중앙 새벽불 마을과 152×136 단일 평원. 구역별 문이나 필수 순서 없음. 적 처치로 균열 100%를 채우면 같은 필드에 수호자가 나타난다. 15분 내 처치하면 다음 단계와 강화 파편 보너스, 초과해도 장비 보상은 지급한다.
- C 마을 정비, G 전체 지도, B 입장/2.5초 귀환/원위치 복귀. 귀환 중 이동·공격·피격 시 취소. Space 스킬과 플레이어 돌진은 없음.
- 장비 강화, 옵션 재설정, 잠금, 선택 분해, 보호되는 빌드 저장 3칸, 무료 초기화, JSON 저장 백업·복원.
- 스킬별 다층 궤적·빛기둥·운석 착탄·서리 파편·화살비, 곰 변신과 야수/뼈 소환체, 타격 모션·소리·선택 가능한 흔들림. 적의 공격 예고는 효과 위에 다시 그린다.

## 검증

`npm test`: 기본 전투, 저장 호환, 무기, 룬, 전설, 마을, 균열, 개인 드롭, 넘친 보상과 스킬 선택 검증. `tests/builds.mjs`는 40스킬×3형태 120회 시전, 8직업 시너지, 영구 혼성 소환 상한, 개인별 추첨 결과를 검사한다.

`npm run test:full`: 8직업 솔로와 3개 협동 조합이 실제 이동·공격 입력으로 균열 완료와 다음 단계 준비까지 진행한다. 협동 자동 조작은 파티가 같은 사냥 대상을 향하도록 한다.

`npm run test:render`: 선택적인 @napi-rs/canvas로 Canvas API를 실행한다. 모든 스킬, 곰, 늑대, 혼성 군단, 지도와 효과 상세 설정을 포함한다. 스크린샷을 생성하지 않는다.

자동 검증은 사람의 손맛 평가나 실제 브라우저 성능을 대신하지 않는다. 이번 작업에서 브라우저 UI 조작·물리 게임패드·기기별 시각 검증은 수행하지 않았다. 온라인 멀티와 클라우드 캐릭터 저장은 구현되지 않았다. 5만원 판매 수준이나 완성도 80점 달성으로 판정한 상태가 아니다. 상세 설계와 다음 품질 기준은 [DESIGN.md](DESIGN.md)에 있다.
