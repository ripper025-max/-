DESIGN YLABS V3.5 — ARCHITECTURAL MOTION UPGRADE

사용 방법
1. 압축을 풀고 index.html을 더블클릭하여 홈페이지를 엽니다.
2. 메인 오른쪽 아래 [메인 사진 수정] 버튼을 눌러 사진 2장을 지정하십시오.
   - 01 흑백 트러스 현장 원본
   - 03 전시장 완성 현장 원본
   - 02는 도면 스타일 SVG가 기본 포함되어 있습니다.
3. [사진 포함 HTML 저장]을 누르면 등록 사진이 포함된 HTML을 다운로드할 수 있습니다.
4. 프로젝트 사진은 admin.html에서 편집할 수 있습니다.
5. 현재 방문자 홈페이지와 관리자 사이의 사진 저장은 브라우저에 한정되며 실서버 자동 게시 기능은 없습니다.

중요
- 현재 제공된 대화 속 업로드 사진의 바이너리를 GitHub에 직접 복사할 수 없는 제한이 있어,
  초기 ZIP의 01·03은 설치·전시장 구조의 컨셉 SVG로 구성했습니다.
  실제 사진을 사용하려면 [메인 사진 수정]에서 원본 파일을 선택해 주세요.
- 사용자가 선택한 Freesentation 웹폰트를 공식 배포 CSS에서 불러옵니다.
- 사진과 글이 슬라이드마다 함께 전환됩니다.
- 이 파일은 관리자 로그인 기능이 없는 개발 미리보기입니다. 공개 사이트에 EDITOR를 노출하지 마십시오.
